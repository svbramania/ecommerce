# Launch catalog — product sourcing research

Documents where the 12-product launch catalog's product picks and category
choices came from, so the "top trending products" claim is traceable instead
of taken on faith. Written when the sourcing was redone on 2026-09-12 at the
user's request after the original research pass wasn't saved anywhere.

**What this is, and isn't:** general market research (search results and
buyer's-guide articles about what's trending/best-selling across ecommerce
in 2026), used to pick real, currently-popular product categories and items.
It is not a pull from any live sales-analytics platform, Amazon Best Sellers
API, or a data source this project is connected to — and none of it was
invented from imagination.

**SKUs**: every SKU currently in the catalog (e.g. `LED-DOG-COLLAR-01`,
`COUNTERTOP-ICE-MAKER-01`) was generated internally when the products were
created — not a supplier-issued model number. Alibaba's search/category
pages are reachable without a bot check, but every individual product-detail
page (the only place a real "Model Number" field would show) is gated behind
a slider CAPTCHA in this environment. That CAPTCHA was not solved (per this
project's standing rule against defeating bot-detection), so no legitimate
supplier SKU could be retrieved. If real supplier SKUs are wanted later, that
requires either solving that CAPTCHA yourself and handing the values over, or
sourcing from a supplier whose catalog doesn't gate detail pages this way.
